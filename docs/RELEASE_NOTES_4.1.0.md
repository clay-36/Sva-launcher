# Sva Launcher 4.1.0

Version code: 6

- Added a full-screen TV guide with category filtering, a shared timeline, live progress, programme reminders, and a Now shortcut.
- Added short, interruptible transitions and focus animations that respect Android animation settings.
- Refined settings, game details, and remote focus spacing.
- Defaulted to dark appearance when no theme is saved, and fixed focused app tiles clipping on Home.
- Redesigned the built-in file browser with consistent folder icons, clearer selection feedback, and stable focus when selecting multiple games.
- Removed Other locations from all file-browser modes. Local files and USB drives use the built-in browser; storage access is requested when browsing, rather than at startup.
- Fixed late background callbacks that could crash the launcher after its activity was destroyed.
- Fixed backup restore draft handling and stale light/dark theme selection.
- Fixed schedule cells drawing over the TV guide channel column while panning.
