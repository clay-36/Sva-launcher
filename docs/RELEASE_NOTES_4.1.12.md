# Sva Launcher 4.1.12

Version code: 17.

- Live TV now uses a four-column, vertically scrolling channel grid. The heading
  and category controls scroll with the channels. Off-screen cards are recycled
  for large provider catalogues.
- Add Xtream Codes accounts from Live TV settings using a server URL, username,
  and password. Imports live channels and categories, generates the XMLTV guide
  source, and preserves existing M3U sources. Movies and series are excluded.
- Aerial video wallpaper and screensaver are available directly inside Sva,
  with independent switches and Apple, Amazon, Jetson Creative, and Robin
  Fourcade collections. Playback is muted, uses 1080p SDR streams, skips stalled
  clips, and releases the player when inactive. Existing photo options remain.
- Aerial screensavers retain the clock, weather, and event overlays. Attribution,
  the upstream source revision, and GPL text are included.
- New settings and validation messages are translated into all 23 supported
  languages. Aerial preferences are included in configuration backups.

Aerial videos require internet access and can use substantial data. System-wide
screensaver activation still requires choosing Sva in Android TV settings.
See [Aerial video setup](AERIAL_VIDEOS.md) and the
[release verification record](RELEASE_REVIEW_4.1.12.md).
